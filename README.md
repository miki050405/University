# University

Информационная система для управления учебными процессами в университете.

## Описание проекта
Система предназначена для цифровизации и частичной автоматизации ключевых процессов образовательного учреждения. Приложение позволяет просматривать расписание, управлять регистрацией студентов на дисциплины, выставлять оценки и выполнять другие учебные операции.

## Роли пользователей
В системе предусмотрены 4 роли:
- Студент
- Преподаватель
- Сотрудник кафедры
- Администратор

## Возможности системы

### Студент
- авторизация в системе;
- просмотр расписания занятий;
- просмотр списка зарегистрированных дисциплин;
- регистрация на дисциплины;
- редактирование и удаление выбранных дисциплин в период регистрации;
- просмотр оценок по предметам.

### Преподаватель
- авторизация в системе;
- просмотр расписания занятий;
- просмотр закреплённых потоков;
- выставление оценок студентам выбранного потока.

### Сотрудник кафедры
- авторизация в системе;
- добавление, просмотр, редактирование и удаление дисциплин кафедры;
- управление занятиями в рамках семестра;
- добавление, просмотр, редактирование и удаление потоков;
- фильтрация потоков по группе и занятию;
- просмотр списка групп;
- фильтрация групп по направлениям;
- просмотр информации о студентах по группам.

### Администратор
- авторизация в системе;
- управление справочными данными (факультеты, специальности, кафедры, студенты и др.);
- фильтрация данных по различным параметрам;
- открытие и закрытие модулей и итогового контроля;
- настройка количества модулей и дополнительных баллов по дисциплинам;
- добавление, редактирование и удаление расписания;
- открытие и закрытие регистрации для выбранных потоков.

## Основные функции
- определение роли пользователя при входе в систему;
- разграничение прав доступа в зависимости от роли;
- проверка корректности вводимых данных;
- хранение данных в базе данных.
